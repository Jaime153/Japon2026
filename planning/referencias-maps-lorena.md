## Instrucciones de uso para Claude y otros agentes

1. Leer este documento cuando se planifiquen Tokio, Kioto, Osaka, Hiroshima, una revisión del itinerario o el diario de viaje. En particular, tener presente la lista de Tokio al proponer actividades complementarias.
2. Un enlace a una lista **no es prueba** de que el grupo haya visitado sus lugares. Tampoco constituye automáticamente una reserva, una prioridad «sí o sí» ni una instrucción para incorporar sus puntos en la ruta diaria.
3. Si se puede abrir la lista, inventariar los puntos con su nombre, barrio/ciudad y URL individual, distinguiendo lo leído directamente de lo que se deduce. **No copiar por adivinación** ni inventar coordenadas/horarios. Consultar a Jaime antes de mover el recorrido para incluir puntos nuevos.
4. Para futuros enlaces, usar este formato:
   - **Área y nombre de la lista:** etiqueta que comparte Lorena.
   - **URL compartida exacta:** sin modificar el enlace.
   - **Procedencia/fecha:** quién la pasó y cuándo.
   - **Estado de lectura:** accesible/verificada o pendiente de consultar.
   - **Lugares destacados:** solo los comprobados y relevantes; no convertirlos en «realizados».
5. Antes de incluir un sitio de la lista en el itinerario, revisar el horario real del día, accesibilidad, distancia respecto a la ruta existente, precio y preferencias más recientes de Jaime y Lorena. Las decisiones reales más recientes de `AGENTS.md` y `src/content/segments/*.json` prevalecen sobre sugerencias históricas.
6. **No conectar/importar este documento desde Astro, `src/data/trip.ts`, `src/content/`, `src/pages/` ni `public/`.** Es una referencia exclusiva para trabajar sobre el código, no para la interfaz, el mapa público, las búsquedas de la web ni el bundle generado.
7. **Privacidad:** este repositorio de GitHub es **público**. Que el archivo no se muestre en GitHub Pages **no lo hace privado**. No guardar aquí ubicaciones personales, direcciones de casas, listas privadas con acceso restringido, números de cuenta, datos personales, tokens o exportaciones personales completas. Si una lista es sensible, mantener el enlace y los datos en una fuente privada fuera del repositorio y documentar solo una referencia neutra.
